# AI & LangChain Workshop

A collection of hands-on Python examples developed while learning and practicing **LangChain, Large Language Models (LLMs), prompt templates, document loaders, text splitting, and LLM-based applications**.

This repository contains small, focused examples covering different concepts rather than a single complete application.

---

## Topics Covered

- Basic LLM interaction
- LLM parameters
- Prompt templates
- Streamlit applications
- Chatbot with conversation history
- Research paper summarization
- External prompt templates using JSON
- PDF document loading
- PDF text chunking
- Recursive text splitting
- Directory-based PDF loading
- CSV document loading
- Text file loading
- Webpage loading and question answering
- OpenAI model listing
- Environment variable management
